# 🛡️ FX AntiRag - Anti-Ragging Platform

[![Download APK](https://img.shields.io/badge/Download-APK-green?style=for-the-badge&logo=android)](https://github.com/8421BCED/anti-ragging-app/raw/main/downloads/FX_AntiRag.apk)

**FX AntiRag** is a high-end, real-time safety platform designed to protect students from ragging on campus. It features a one-tap SOS system, real-time location tracking, and a premium admin dashboard for campus authorities.

---

## ✨ Key Features

### 📱 Mobile App (Android)
- **🚀 One-Tap SOS**: Instantly triggers an emergency alert with a 3-second cancellation window.
- **📍 Live Location**: Automatically sends GPS coordinates to the admin during SOS or complaint filing.
- **📝 Smart Complaints**: File detailed reports with images, department info, and anonymity options.
- **🗂️ History Hub**: Track the status of all your past reports and SOS alerts in real-time.
- **🔔 Instant Notifications**: Get notified the moment an admin reviews your report.

### 💻 Admin Command Center (Web)
- **📊 Glassmorphism Dashboard**: A stunning, modern interface for real-time monitoring.
- **🔴 Live SOS Alerts**: Instant alerts with direct links to Google Maps for rapid response.
- **✅ Complaint Management**: Approve or decline reports with one click.
- **🧹 Data Control**: Easily clear old alerts and manage the database history.

## 🚀 Installation

### Mobile
1. Click the **[Download APK](https://github.com/8421BCED/anti-ragging-app/raw/main/downloads/FX_AntiRag.apk)** button at the top.
2. Install the file on your Android device (Enable "Install from Unknown Sources" if prompted).
3. Open the app and grant Location permissions.

### Admin Panel (Dev Mode)
1. **Frontend**:
   ```bash
   cd admin/frontend
   npm install
   npm run dev
   ```
2. **Backend**:
   ```bash
   cd admin/backend
   pip install -r requirements.txt
   python app.py
   ```

## 🛠️ Technology Stack
- **Android**: Kotlin, Jetpack ViewBinding, Supabase-kt, Ktor.
- **Web**: React.js (Frontend), Flask (Backend).
- **Database**: Supabase (Realtime, Postgrest, Storage).
- **UI/UX**: Custom Glassmorphism, Material Design 3.
